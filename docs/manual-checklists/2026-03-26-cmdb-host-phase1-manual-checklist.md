# CMDB Host Phase 1 Manual Checklist

1. 打开 `http://10.0.0.200:8080/cmdb/ecs`，确认主机列表正常加载，没有白屏和接口报错。
2. 勾选 2 台以上主机，确认列表上方出现批量工具条，并显示已选数量。
3. 点击“批量测试连通性”，确认先出现二次确认，再看到成功/失败统计和失败原因。
4. 点击“批量同步”，确认先出现二次确认，再看到同步结果摘要；若选择了 Windows 或未配 SSH 的主机，应看到跳过提示。
5. 打开一台 Linux 主机详情，确认“连接中心”中 `Web SSH / 执行命令 / 文件上传 / 配置同步` 都有明确入口或状态。
6. 在 Linux 主机详情里点击 `Web SSH`，确认仍能跳转到原有 `/cmdb/ssh` 终端页。
7. 在 Linux 主机详情里点击 `执行命令`，输入低风险命令，如 `pwd` 或 `ls /tmp`，确认可直接执行并返回输出。
8. 在 Linux 主机详情里输入中风险命令，如 `systemctl restart nginx`，确认先出现风险提示，再二次确认后才执行。
9. 在 Linux 主机详情里输入高风险命令，如 `rm -rf /tmp/demo`，确认出现更强风险提示，并且必须再次确认。
10. 打开一台 Windows 主机详情，确认可以看到 `RDP 地址 / 端口 / 用户 / 域` 信息。
11. 在 Windows 主机详情里确认 `Web SSH / 执行命令 / 文件上传 / 配置同步` 不是消失，而是禁用态并带原因说明。
12. 在主机详情里查看“终端审计”区域，确认能看到最近会话摘要；没有数据时应看到空态提示。
13. 从主机详情点击“查看审计”，确认跳转到 `/monitor/recording`，并且筛选条件已自动带入当前主机。
14. 从主机详情点击“最近风险命令”，确认跳转后的终端审计页已带入风险筛选。
15. 回归检查既有功能未受影响：
    编辑主机、上传文件、配置同步、进程监控、TCP 端口监控。
