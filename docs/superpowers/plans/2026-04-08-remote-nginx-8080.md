# Remote Nginx 8080 Frontend Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the OpsNexus frontend on `http://10.0.0.203:8080/` while keeping the API on `127.0.0.1:8000` behind nginx reverse proxy.

**Architecture:** Reuse the repository's existing remote nginx config pattern, deploy `web/dist` to the target host, install and configure nginx to listen on `8080`, and proxy `/api/` plus `/api/v1/upload` to the already-running backend service on `8000`. Keep the backend systemd service unchanged except for the frontend integration around it.

**Tech Stack:** Vue static build output, nginx, existing remote deployment PowerShell script, systemd-managed Go API
