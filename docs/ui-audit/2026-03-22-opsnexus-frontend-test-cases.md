# OpsNexus 前端详细测试用例

## 基线
- 文档日期: 2026-03-22
- 测试环境: `http://10.0.0.200:8080`
- 测试账号: `admin`
- 基准视口: 1280x900
- 菜单来源: 共享环境管理员真实菜单树
- 路由覆盖: 44 个唯一路由，模块结构按当前共享环境菜单生成

## 通用前置条件
- 使用 Chrome 或 Edge 最新稳定版。
- 登录共享环境后，从左侧菜单进入对应模块页面。
- 默认以 1280x900 视口执行桌面端测试，再抽样用 1440x900 与 960px 宽度复核。
- 若页面涉及分页、弹窗、抽屉、详情区，至少执行一次打开与关闭操作。

## 通用判定标准
- 不允许页面首屏出现明显错位、遮挡、按钮重叠、标题挤压。
- 数据密集页允许存在横向滚动，但不能让主列、状态列和核心操作列同时被挤出首屏。
- 所有 tooltip、tag、按钮、分页、空态、loading、弹窗都必须有稳定布局。

## 资产管理

### 主机管理
- 路由: `/cmdb/ecs`
- 页面类型: table
- 现场结论: 严重
- 关注点: 左侧分组树与右侧主机表并排布局、搜索区与主机操作区
- 巡检观察: 首屏即出现重度横向滚动，最大横向超出 718px，核心列和操作列可见性受影响。
- 现场截图: [01-资产管理-主机管理.png](C:/zq/平台开发/OpsNexus/OpsNexus/tmp/opsnexus-browser-artifacts/full-ui-audit/crawl/01-资产管理-主机管理.png)

#### 资产管理-主机管理-001 主机管理首屏布局与信息层级
- 前置条件: 已使用 admin 登录；打开路由 `/cmdb/ecs`；浏览器视口为 1280x900。
- 步骤:
  1. 观察页头、工具栏、主体表格、分页区是否在一个垂直阅读流内。
  2. 确认面包屑、标题、副标题、统计卡或提示区没有互相遮挡。
  3. 确认页面首屏没有出现横向滚动条抢占主体注意力。
- 预期结果:
  - 页面无白屏、无错位、无遮挡。
  - 至少名称/主键列、状态列和主操作列在首屏可见，横向滚动仅承载次要信息。
  - 筛选区与表格之间间距统一，页脚分页不会贴边或漂浮。
- 优先级: P0

#### 资产管理-主机管理-002 主机管理筛选工具栏换行与密度
- 前置条件: 保持当前页面；准备输入任意查询条件。
- 步骤:
  1. 依次输入长关键字、选择下拉项、清空条件。
  2. 缩小浏览器宽度到 1280px 左右，观察工具栏是否发生合理换行。
  3. 检查搜索、重置、刷新、新增等按钮是否仍能完整显示。
- 预期结果:
  - 输入框、下拉框、按钮不会重叠或压缩到不可点击。
  - 换行后按钮顺序稳定，主要动作仍在右侧或最后一行清晰可见。
  - 表单标签不会与控件基线错位。
- 优先级: P0

#### 资产管理-主机管理-003 主机管理表格主列与操作列可见性
- 前置条件: 当前页面存在列表数据；若无数据，则切换到有数据环境或验证空态。
- 步骤:
  1. 观察表格默认列宽分配，记录主列、状态列、时间列、操作列的首屏可见情况。
  2. 检查是否需要先横向滚动才能看到操作列。
  3. 悬浮在长文本单元格上，确认 tooltip 与裁切策略是否一致。
- 预期结果:
  - 主列、状态列、核心操作列不应同时被挤出首屏。
  - 如果存在横向滚动，应固定操作列在右侧或提供更高优先级的列压缩策略。
  - 长文本裁切后有明确 tooltip，不会出现文本直接被截断且无反馈。
- 优先级: P0

#### 资产管理-主机管理-004 主机管理行内操作与弹窗/抽屉布局
- 前置条件: 当前页存在可操作数据行。
- 步骤:
  1. 点击详情、编辑、删除、审批、执行、解密等主要操作之一。
  2. 观察弹窗或抽屉的宽度、表单分组、底部按钮区以及遮罩层表现。
  3. 关闭后再次打开，确认布局不抖动。
- 预期结果:
  - 操作按钮命中区清晰，不会因列宽不足而挤成两行难以点击。
  - 弹窗/抽屉标题、主体、页脚分区明显，按钮区不会被内容区挤压。
  - 关闭后页面不会残留错位遮罩或滚动锁定异常。
- 优先级: P1

#### 资产管理-主机管理-005 主机管理分页、空态与异常态呈现
- 前置条件: 准备一组可命中和一组不可命中的查询条件。
- 步骤:
  1. 用不可命中的条件触发空结果。
  2. 恢复正常条件并切换分页、页大小。
  3. 观察 loading、空态、分页条、总数提示的排版。
- 预期结果:
  - 空态组件应在表格区域中居中展示，不会留大面积脏背景或错位。
  - 分页条与总数信息保持同一视觉层级，切换页码不跳动。
  - loading 状态不会导致表头抖动或按钮位移。
- 优先级: P1
